What is ParaMesh?

It makes separate laptops behave like one computer for your program. You write C as if all the memory were in one place, and ParaMesh moves the data for you.

Distributed shared memory

Every laptop sees the same addresses. If the page your program touches is on another machine, ParaMesh pauses that thread, fetches the page and carries on. Your code never mentions the network.

Memory coherence

Many laptops can read a page at once, but only one can write it. Before a write, the other copies are invalidated, so nobody reads stale data.

Parallel task execution

Split a loop into chunks and worker threads take them as they finish, so a faster laptop simply does more.

Transparent communication

There is no socket code in your program. The runtime catches page faults with userfaultfd and talks to the other laptops over TCP.

Shared computing resources

Each laptop chooses how many cores and how much RAM to give. Its own jobs come first on its own cores. A ledger values a peer's work at what the same work costs here, so nothing a peer claims counts.

How it works

1

Connect machines

Linux laptops on one network join the same pool from their dashboards.

2

Write a program

Ordinary C, using the ParaMesh interface.

#include <paramesh.h>
PM_TASK(square) { ... }
3

Distribute computation

pmrun -n N uses this machine and the peers with the most free capacity. Tasks wait in a queue here, and each machine takes chunks.

pm_parallel_for("square",
  0, n, 0, &a, sizeof a);
4

Access shared memory

Every node reads and writes one coherent region. Pages move when they are needed.

5

Obtain results

The program finishes on the machine that started it, and prints its output.

Architecture

The same program runs on every node. These are the parts, as they are in the code.

pmrun
Starts the launcher and asks the local pmd for N nodes.
pmd
One daemon on each machine. It finds the other daemons, admits jobs and picks the peers with the most free capacity, each of which may decline. It starts the worker processes.
Launcher and workers
The same executable. main() runs on the launcher, which also holds the task queue and manages locks and barriers. Tasks run everywhere.
Coherence
Each page has a home node that tracks who holds it and hands out read or write access.
Lost nodes
If a node disappears the job ends with a message. ParaMesh never makes up the lost data.
