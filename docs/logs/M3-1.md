## Decisions

<!--
Choices you made inside the card's scope, each with the reason. Not for points listed under
"Still open" in the plan: those are asked, never decided here. Write "None" if there were none.
-->
- **The macro body in `paramesh.h` stays as it is.** The card allows changing it; the draft
  already emits a constructor that calls `pm_register_task`, and works in C and in C++.
- **A forced collision goes through `rt_register_task_as(name, id, fn)`,** which registers
  under a given ID. Two different names with one real FNV-1a hash would take a search of about
  2^32 names to find. The same name registered twice needs no forcing and is tested as well.
- **The clash message is kept in the registry,** because `Error::what` is a plain pointer.
- **`pm_init()` prints and exits with status 1** on a clash, before it reads anything else:
  there is no job yet to abort.
- **A chunk for an ID this binary does not have ends the job** like a throwing task. All
  nodes run the same binary, so it cannot happen between correct processes.
- **The registry is a vector searched from the front.** Marked `ponytail:`; a job has a
  handful of tasks.
