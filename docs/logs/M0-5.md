- [answered 2026-10-06 by Amirishetty Sai Vignesh] (M0-4's G2, asked before starting because
  it decides the launch sequence in this document.) How is a job's region size admitted:
  through the launcher's `pm_init()`, or through a `pmrun --region` flag? Answer: through
  `pm_init()`. The launcher process starts first, its `pm_init()` sends the region size to the
  local pmd, and pmd admits or refuses before any worker is spawned; `pm_init()` returns
  `PM_ERR_REFUSED` on refusal. Consequence the person accepted: M4-4's "refused before any
  process starts" becomes "before any worker starts". That sentence is in `docs/PLAN.md`, which
  only the person edits; it is to be recorded with the gate answers.
