## Decisions

<!--
Choices you made inside the card's scope, each with the reason. Not for points listed under
"Still open" in the plan: those are asked, never decided here. Write "None" if there were none.
-->
- **Sources found by glob, one helper per directory.** `paramesh_module()` globs `*.c`/`*.cpp`
  (`CONFIGURE_DEPENDS`); `tests/unit` turns each `*_test.cpp` into its own executable; `apps/`
  adds any subdirectory with a `CMakeLists.txt`. Reason: the plan wants later tasks never to edit
  the same build file, and parallel tasks share directories (M4-2 and M4-3 in `src/store/`, every
  stream in `tests/unit/`). Explicit source lists would make each of them edit one file.
- **Empty directories are INTERFACE targets** that carry the include root (`src/`) and the
  dependency edges from the plan's layout table; the helper makes them static libraries when the
  first source appears. CMake cannot build a static library with no sources.
- **Exceptions off** for the eight directories that make up `libparamesh` (`platform`, `wire`,
  `coh`, `mem`, `store`, `net`, `rt`, `lib`); on for `pmd`, `tools` and tests. `platform` is
  linked into `libparamesh`, so it is off too; M0-3 owns `src/platform/CMakeLists.txt` if the
  HTTP adapter (used by `pmd`) needs exceptions or `CPPHTTPLIB_NO_EXCEPTIONS`.
- **Warning set:** `-Wall -Wextra -Wpedantic -Wshadow -Wconversion -Wsign-conversion -Wcast-align
  -Wnull-dereference -Wdouble-promotion -Wformat=2 -Wimplicit-fallthrough -Wundef`, plus for C++
  `-Wnon-virtual-dtor -Wold-style-cast -Woverloaded-virtual`, with `-Werror` (option
  `PARAMESH_WERROR`, default ON). Only flags both GCC and Clang accept.
- **Sanitizers apply to the whole build**, third-party code included, so TSan sees every access.
  UBSan uses `-fno-sanitize-recover=all` so a finding fails the test.
- **TSan via `setarch -R` rather than lowering `vm.mmap_rnd_bits`.** Needs no root, works on the
  laptops and on the Actions runner alike.
- **clang-format:** Google base, 4-space indent, 100 columns, braces always.
- **clang-tidy:** bugprone, cert, clang-analyzer, concurrency, cppcoreguidelines, misc, modernize,
  performance, portability, readability, all as errors; each exclusion carries its reason in
  `.clang-tidy`. Naming: `CamelCase` types, `lower_case` functions and variables, `k` constants,
  trailing `_` on private members. Reason: three agents writing in parallel need one convention.
- **CI:** `ubuntu-24.04` (same distribution as the laptops); GCC and Clang, each without a
  sanitizer and under all three; format and tidy jobs; build jobs skip PR "edited" events, which
  only re-run the log check.
- **Vendoring layout:** `third_party/<lib>/include/` plus licence and a README with SHA-256 of
  each file; `SYSTEM` include directories so our warnings and tidy skip them.
- **CMake 3.25 minimum** (presets version 6). Ubuntu 24.04 ships 3.28. Default build type Debug.
- **`include/` is not created here.** `paramesh.h` is M0-4's; `paramesh::api` already points at
  `include/`.
