Local, 2026-10-09 (kernel 7.0.0-38).

**Done-when: a write to a shared page raises one event and resumes after the grant.**
Case "a write to a shared page raises one event and resumes after the grant": a page is
installed read-only; a thread writes it; one `kWrite` event arrives and the thread stays
parked while a reader still reads the old byte; `write_protect(page, false)` resumes it; a
second write raises nothing; the sink has counted exactly 1 event; the other bytes of the
page are unchanged. Passed.

`build/dev/tests/unit/unit_mem_test`: 19 cases (3 new), 151 assertions, all passed.

| The other two cases | Events | Result |
| --- | --- | --- |
| discarded while parked, then installed writable | 1 | the write lands on the new page |
| write-protect, copy out, discard, wake, install | 2 (the same write, twice) | the copy sent holds the old byte; the write lands after the install |

Repeats: the mem tests 30 times in the dev build and 15 times each under gcc ASan and clang
UBSan: 0 failures. They are skipped under TSan, as every test that maps the region is.

Quality gate: all eight compiler and sanitizer builds pass, 15/15 tests (14/14 under TSan), no
warnings; clang-tidy exit 0; clang-format clean.
